# Real-Time Heart Murmur Detection using Deep Learning

## 📌 Overview

This project focuses on the development of a real-time Heart Murmur Detection system using Deep Learning and Phonocardiogram (PCG) signal analysis. The system is designed to assist in the early detection of abnormal heart sounds by analyzing cardiac auscultation recordings using AI-based techniques.

The project combines biomedical signal processing, spectrogram analysis, and deep learning models to classify normal and abnormal heart sounds efficiently.

---

## 🎯 Objectives

- Detect heart murmurs from PCG signals
- Perform real-time cardiac sound classification
- Apply deep learning techniques for biomedical signal analysis
- Improve early screening support for cardiovascular abnormalities
- Explore lightweight AI solutions for healthcare applications
